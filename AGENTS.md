# Regole del progetto

- Lavorare su sviluppo. Non unire o pubblicare codice applicativo su main senza conferma esplicita dell'utente.
- Nessuna inferenza IA cloud. Dati reali e pesi dei modelli restano fuori da Git.
- Documentare separatamente funzionalità implementate e pianificate.
- Eseguire i test pertinenti; per il backend usare python -m pytest.
- Non sovrascrivere audio originali o correzioni manuali delle dispense.
